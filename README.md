# Phone Chat UI (SillyTavern extension)

หน้าจอแชทมือถือที่ซ้อนทับบนแชทปัจจุบันของ SillyTavern — ไม่แทนที่ระบบแชทเดิม
ส่งข้อความผ่านปุ่มส่งของ SillyTavern เอง ดังนั้น preset / world info / lorebook ทำงานเหมือนเดิมทุกอย่าง
ตอนปิดหน้าจอโทรศัพท์ extension นี้แทบไม่ทำงานเลย (ไม่เสียสเปค)

## ฟีเจอร์

- **แชท**: บับเบิลโค้งมน, avatar กลม, เวลาใต้ข้อความ, ตัวคั่นวัน (วันนี้ / เมื่อวาน), แสดง "กำลังพิมพ์…" ระหว่างบอทตอบ,
  `*แอ็กชัน*` แสดงเป็นตัวเอียง, ข้อความบอทที่มีหลายย่อหน้าแยกเป็นหลายบับเบิลเหมือนส่งรัวๆ, ปุ่ม "ตอบกลับ" ข้อความใดข้อความหนึ่ง
- **วันที่/เวลา**: นาฬิกาบนสุด, เวลาในทุกข้อความ และบอทรู้เวลาจริงตอนนี้ (ดูหัวข้อ "ทำให้บอทมีชีวิต")
- **แจ้งเตือน**: ตอนปิดหน้าจอโทรศัพท์ ถ้าบอทตอบมา จะมีแบนเนอร์เด้งด้านบน กดแล้วเปิดแชทได้เลย (เปิดเสียงเตือนได้ในตั้งค่า)
- **โทร**: กดไอคอนโทรศัพท์ → โทรออก → สักพักบอทรับสายและพูดก่อน → พิมพ์คุยกันบนหน้าจอโทร มีตัวจับเวลา
  บอทโทรหาคุณเองได้ (สายเรียกเข้า รับ/ปฏิเสธ/ไม่รับ) ทุกสายบันทึกเป็นแถว "โทรออก · 3:12" ในแชท
- **ปฏิทิน**: ปฏิทินรายเดือน กดวันเพื่อดูนัด เพิ่มนัดเองได้ และบอทเพิ่มนัดให้เองได้ มีแจ้งเตือน 15 นาทีก่อน และตอนถึงเวลา
- **ธีม**: ออกแบบเอง ไม่ลอกแอปไหน ปรับสีหลักได้ในตั้งค่า

## ติดตั้ง

1. แตก zip ได้โฟลเดอร์ `phone-chat-ui` (ข้างในมี `manifest.json`, `index.js`, `style.css`)
2. วางโฟลเดอร์ไว้ที่ใดที่หนึ่งนี้
   - `SillyTavern/public/scripts/extensions/third-party/phone-chat-ui/` (ใช้ได้ทุก user)
   - `SillyTavern/data/<ชื่อ-user>/extensions/phone-chat-ui/` (เฉพาะ user นั้น)
3. รีเฟรชหน้าเว็บ SillyTavern (หรือรีสตาร์ทเซิร์ฟเวอร์) แล้วไปที่ Extensions → ติ๊กเปิด **Phone Chat UI**

ต้องใช้ SillyTavern เวอร์ชันใหม่พอที่มี `SillyTavern.getContext()` และ `generate_interceptor` (ยังไม่ได้ตรวจหาเวอร์ชันขั้นต่ำที่แน่ชัด แนะนำรุ่นล่าสุด)

## วิธีใช้

- เปิดจากเมนูไม้กายสิทธิ์ 🪄 ข้างช่องพิมพ์ → **หน้าจอโทรศัพท์** (ปิดด้วยลูกศรซ้ายบนหรือกด Esc)
- พิมพ์ในช่องของหน้าจอโทรศัพท์ได้เลย (Enter ส่ง, Shift+Enter ขึ้นบรรทัดใหม่ — บนมือถือ Enter คือขึ้นบรรทัดใหม่)
- ไอคอน 📅 = ปฏิทิน, ไอคอน 📞 = โทรหาบอท

## ทำให้บอทมีชีวิต

เฉพาะตอนเปิดโหมดโทรศัพท์ extension จะแทรกโน้ตสั้นๆ ให้บอทตอนสร้าง prompt ทุกครั้ง (ผ่านกลไก prompt interceptor ของ SillyTavern — ไม่แก้ character card):

- วัน/เวลาจริงตอนนี้ → บอทพูดถึง "เช้านี้ / คืนนี้ / พรุ่งนี้" ได้ถูกต้อง
- นัดหมายที่จะถึงในปฏิทิน และประวัติการโทรล่าสุด (รวมสิ่งที่คุยกันตอนโทร) → บอทอ้างถึงได้เหมือนจำได้
- ให้ตอบสั้นแบบข้อความแชท (เปิดอยู่ตามค่าเริ่มต้น ถ้าอยากให้บอทเขียนยาวเหมือนเดิม ให้ปิดในตั้งค่า)
- บอกวิธีใช้แท็กลับ: `[[calendar: ชื่อนัด || YYYY-MM-DD HH:mm]]` เพื่อเพิ่มนัด และ `[[call]]` เพื่อโทรหาคุณ

คุณไม่ต้องเขียนอะไรเพิ่มใน character card — บอทจะใส่แท็กเองเมื่อเหมาะกับเรื่อง
extension ตัดแท็กออกจากบับเบิลให้ แต่ในแชทปกติของ SillyTavern จะยังเห็นแท็กอยู่ ถ้าไม่อยากเห็น
ให้เพิ่ม Regex (Extensions → Regex) ค้นหา `\[\[\s*(?:calendar|call)\b[^\]]*\]\]` แทนที่ด้วยว่าง และติ๊ก "Alter Chat Display" อย่างเดียว

### รูปแบบวันเวลาที่เข้าใจ

`2026-10-09 18:00` · `tomorrow 6pm` · `พรุ่งนี้บ่าย 3` · `พรุ่งนี้ 2 ทุ่ม` · `มะรืนนี้ 10:30` ·
`in 2 hours` · `อีก 30 นาที` · `friday 19:30` · `วันเสาร์ 10 โมงเช้า` · `next monday 9am` · `เที่ยง` · `บ่ายโมง`
(ถ้าบอทเขียนอ่านไม่ออกจะไม่เพิ่มนัด — ไม่พัง)

## ตั้งค่า (Extensions → Phone Chat UI)

แจ้งเตือนข้อความใหม่ · เตือนนัดหมาย · ให้บอทรู้เวลา/นัด/ประวัติโทร · ให้บอทตอบสั้นแบบแชท · เสียงแจ้งเตือน · สีธีม
และปุ่มทดสอบ "สายเรียกเข้า" / "แจ้งเตือน"

## ข้อจำกัด

- การโทรเป็นการคุยด้วยข้อความบนหน้าจอโทร ไม่ใช่เสียงจริง (เรียก AI เบื้องหลังเหมือนแชทปกติ ใช้โควตา/โทเคนตามปกติ)
- ปฏิทินและประวัติการโทรผูกกับ **แชทที่เปิดอยู่** (เก็บใน chat metadata) สลับแชทแล้วจะเห็นของแชทนั้น
  ถ้าสลับแชทระหว่างโทร สายจะถูกตัดทิ้งโดยไม่บันทึก
- ในหน้าจอโทรศัพท์ยังไม่มีปุ่ม swipe / แก้ไข / regenerate — ปิดหน้าจอโทรศัพท์แล้วใช้ในแชทปกติได้เหมือนเดิม
- ถ้าบอทเขียนแท็ก `[[call]]` ตอนปิดหน้าจออยู่ หน้าจอโทรศัพท์จะเปิดขึ้นมาเพื่อให้สายเรียกเข้า
- ผ่านการทดสอบอัตโนมัติกับ SillyTavern จำลองใน Chromium (ตัวแปลงวันเวลา, แชท, แจ้งเตือน, โทร, ปฏิทิน) แต่ยังไม่ได้ลองบน SillyTavern จริง
  ถ้าเจอปัญหา ดู Console ของเบราว์เซอร์ (F12) หาข้อความที่ขึ้นต้นด้วย `[PhoneChatUI]`

## แก้ปัญหาเบื้องต้น

- ไม่เห็นปุ่ม "หน้าจอโทรศัพท์" ในเมนู 🪄: เช็คว่าเปิด extension แล้ว และรีเฟรชหน้าเว็บ
- นัดไม่เข้าปฏิทิน: เช็คว่าเปิดโหมดโทรศัพท์ตอนคุย และตัวเลือก "ให้บอทรู้เวลา…" เปิดอยู่ (ไม่งั้นบอทไม่รู้จักแท็ก)
- ดีบักผ่านคอนโซล: `PhoneChatUI.open()`, `PhoneChatUI.incomingCall()`, `PhoneChatUI.buildContextNote()` (ดูว่าบอทได้รับโน้ตอะไร),
  `PhoneChatUI.parseWhen('พรุ่งนี้ 2 ทุ่ม')`
