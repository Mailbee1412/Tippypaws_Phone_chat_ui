# Phone Chat UI (SillyTavern extension) — v2

โทรศัพท์ในเนื้อเรื่อง: **เนื้อเรื่องยังอยู่ในแชทหลักของ SillyTavern เหมือนเดิมทุกอย่าง**
พอเรื่องพูดถึงมือถือ — มีคนทักมา / เราทักใครไป / มีสายเข้า / มีโพสต์ — โทรศัพท์จะ **เด้งแชท** ขึ้นมาให้เห็นว่าใครพิมพ์อะไร
แยกเป็นแอปต่างๆ (LINE, Messenger, SMS, IG, …) แล้วกดตอบในโทรศัพท์ได้ ข้อความที่ตอบจะถูกส่งเข้าเนื้อเรื่องให้เอง

ตอนปิดโทรศัพท์ extension แทบไม่ทำงานเลย (ไม่กินสเปค) และไม่แทนที่ระบบแชทเดิม — preset / world info / lorebook ใช้ได้เหมือนเดิม

## ภาพรวมการทำงาน

1. เนื้อเรื่อง (บอท) เล่าตามปกติ เช่น *มือถือสั่น เมลบีเหลือบมองหน้าจอ*
   พร้อมแท็กลับท้ายข้อความ `[[msg: เคชินทร์ || LINE || ถึงไหนแล้ว]]` — extension สอนบอทให้ใส่แท็กเองผ่านโน้ตที่แทรกตอนสร้าง prompt (ไม่ต้องแก้ character card)
2. extension ซ่อนแท็กในแชทหลัก แทนด้วยป้ายเล็กๆ `📱 ข้อความใหม่จาก เคชินทร์` (กดแล้วเปิดโทรศัพท์) แล้ว **เด้งแบนเนอร์** ด้านบน
3. กดแบนเนอร์ → โทรศัพท์เปิดที่ห้องแชทนั้น เห็นบับเบิลข้อความ ตอบได้เลย
4. สิ่งที่พิมพ์ตอบในโทรศัพท์ถูกส่งเข้าเนื้อเรื่องเป็นบรรทัด `📱 [LINE › เคชินทร์] ข้อความ` บอทเห็นแล้วเล่าต่อ และให้คนนั้นตอบกลับมาในโทรศัพท์ได้
5. ถ้าบอทลืมใส่แท็กแต่เนื้อเรื่องพูดถึงมือถือ extension จะถามเอไอเบื้องหลังหนึ่งครั้งว่า "เกิดอะไรขึ้นบนมือถือ" แล้วสร้างข้อความให้ (ปิดได้ในตั้งค่า เพราะใช้โควตาเพิ่ม)

ข้อมูลในโทรศัพท์ **อ่านจากข้อความในแชทเสมอ** — swipe / แก้ไข / ลบข้อความ / รีโหลด แล้วโทรศัพท์ตามถูกต้องเอง ไม่ค้าง

## แอปในโทรศัพท์

- **แอปแชท** แยกไอคอนต่างหาก (ค่าเริ่มต้น LINE, Messenger, SMS, IG — แก้ได้ในตั้งค่า) แอปไหนที่เรื่องเอ่ยถึงจะโผล่เพิ่มเอง มีเลขข้อความที่ยังไม่อ่านบนไอคอน
  ชื่อแอปภาษาไทยก็เข้าใจ เช่น ไลน์ → LINE, ไอจี → IG, เมสเซนเจอร์ → Messenger
- **โทร** ประวัติการโทร + กดโทรหาตัวละครได้ (คุยกันเป็นข้อความบนหน้าจอโทร มีจับเวลา) สายเรียกเข้าเมื่อบอทใส่ `[[call: ชื่อ]]` มีรับ/ปฏิเสธ/ไม่รับ
- **ปฏิทิน** นัดหมายที่เรื่องตกลงกัน (`[[calendar: ชื่อนัด || พรุ่งนี้ 18:00]]`) และเพิ่มเองได้ มีแจ้งเตือนก่อนถึงเวลา
- **โซเชียล** ฟีดโพสต์จากตัวละคร (`[[post: ชื่อ || IG || ข้อความ]]`) กดหัวใจได้
- **ปุ่มโทรศัพท์ลอย** โผล่เฉพาะตอนมีข้อความที่ยังไม่อ่าน (มีเลขกำกับ) — ถ้าค้างอยู่ห้องเดียวกดแล้วเข้าห้องนั้นเลย
- นาฬิกา / วันที่ บนโทรศัพท์ + บอทรู้วัน-เวลาจริง (ใช้เป็นข้อมูลอ้างอิงเท่านั้น ไม่ทับไทม์ไลน์ของเรื่อง)

## ติดตั้ง

**จาก GitHub (แนะนำ):** Extensions → Install extension → วางลิงก์ repo นี้ → Install แล้วรีเฟรชหน้าเว็บ
(อัปเดตรุ่นใหม่: Extensions → ปุ่มอัปเดตข้าง Phone Chat UI หรือ "Update all")

**ด้วยมือ:** วางโฟลเดอร์ที่มี `manifest.json`, `index.js`, `style.css` ไว้ที่
`SillyTavern/public/scripts/extensions/third-party/phone-chat-ui/` (ทุก user) หรือ
`SillyTavern/data/<user>/extensions/phone-chat-ui/` (เฉพาะ user นั้น) แล้วรีเฟรช

เปิดโทรศัพท์: เมนูไม้กายสิทธิ์ 🪄 ข้างช่องพิมพ์ → **หน้าจอโทรศัพท์** (ปิดด้วยลูกศร/กด Esc)

## ตั้งค่า (Extensions → Phone Chat UI)

- แจ้งเตือนข้อความ/โพสต์ใหม่ (แบนเนอร์)
- **เปิดแชทขึ้นมาเองทันที** ที่มีข้อความเข้า (ไม่ต้องกดแบนเนอร์) — ปิดไว้เป็นค่าเริ่มต้นเพราะโทรศัพท์จะทับเนื้อเรื่องที่กำลังอ่าน
- ปุ่มโทรศัพท์ลอย
- แอปแชทที่โชว์บนหน้าโฮม (คั่นด้วย `,`)
- เตือนนัดหมาย · บอกบอทเรื่องแท็ก/เวลา/นัด · จับคำเกี่ยวกับมือถือด้วยเอไอเมื่อบอทลืมแท็ก · ซ่อนแท็กในแชทหลัก · เสียงเตือน · สีธีม
- ปุ่มทดสอบ "สายเรียกเข้า" / "แจ้งเตือน"

## แท็กทั้งหมด (บอทใส่เอง — คุณไม่ต้องพิมพ์)

```
[[msg: ผู้ส่ง || แอป || ข้อความ]]      มีคนทักมา
[[sent: ผู้รับ || แอป || ข้อความ]]     เราทักเขาไป
[[post: ผู้โพสต์ || แอป || ข้อความ]]   โพสต์โซเชียล
[[call: ผู้โทร]]                        สายเรียกเข้า
[[calendar: ชื่อนัด || วันเวลา]]       นัดหมาย (เช่น 2026-10-12 18:00, พรุ่งนี้บ่าย 3, อีก 2 ชั่วโมง)
```

## ข้อจำกัด / ที่ควรรู้

- ผ่านการทดสอบอัตโนมัติใน Chromium กับ SillyTavern **จำลอง** (แท็ก → แบนเนอร์/ห้องแชท, ตอบจากโทรศัพท์เข้าเนื้อเรื่อง, AI สำรอง, สายเข้า, ปฏิทิน, แก้/ลบข้อความ, สลับแชท, ความปลอดภัย XSS) แต่ **ยังไม่ได้ลองบน SillyTavern จริง** — ถ้าเจอปัญหา เปิด Console (F12) ดูข้อความที่ขึ้นต้นด้วย `[PhoneChatUI]`
- บอทแต่ละโมเดลทำตามแท็กได้ไม่เท่ากัน ถ้าบางครั้งไม่ใส่ ระบบ AI สำรองจะช่วยจับ (หรือไปเพิ่มในโน้ตของ preset ได้)
- ปฏิทิน ประวัติโทร และข้อความที่ AI สำรองสร้างให้ ผูกกับ **แชทที่เปิดอยู่** (เก็บใน chat metadata) สลับแชทแล้วเห็นของแชทนั้น
- การโทรเป็นข้อความบนหน้าจอโทร ไม่ใช่เสียงจริง และใช้โควตา/โทเคนตามปกติ
- ถ้าอยากดูว่าบอทได้รับโน้ตอะไร: Console → `PhoneChatUI.buildContextNote()`

## ไฟล์ในโปรเจกต์

`manifest.json`, `index.js` (รวม helper ไว้ในไฟล์เดียว), `style.css`, `README.md` — ใช้ไอคอน Font Awesome ที่ SillyTavern มีอยู่แล้ว ไม่มี dependency ภายนอก ไม่ใช้โลโก้ของแอปจริง
